WEBSITE SECURITY

网站安全

我们重视网站安全，并采取合理措施保护网站及客户信息。

1. HTTPS 安全连接

本网站通过 HTTPS 安全连接访问，以帮助保护浏览器与网站之间的数据传输。

2. 网站托管安全

本网站使用专业的网站托管及网络安全服务，以提高网站的稳定性和安全性。

3. 信息保护

对于客户主动提供的个人信息，我们会采取合理措施进行保护，并仅在提供咨询、订单及配送服务所需的范围内使用。

4. 第三方服务

网站可能使用 WhatsApp、网站分析、广告及其他第三方服务。相关第三方服务可能按照其自身的安全和隐私政策处理数据。

5. 安全提醒

请勿通过非官方渠道向任何人提供您的密码、银行卡信息或其他敏感信息。如发现可疑情况，请及时与我们联系。

6. 安全更新

我们会根据网站运行情况及技术需要，对网站进行必要的维护和安全更新。

7. 联系我们

如果您发现网站存在异常或安全问题，欢迎通过 WhatsApp 联系我们。
