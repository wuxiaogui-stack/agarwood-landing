أمان الموقع

نحرص على توفير تجربة تصفح آمنة وموثوقة وحماية المعلومات التي يتم تقديمها من خلال الموقع.

1. اتصال آمن

يستخدم الموقع اتصالاً مشفراً عبر HTTPS للمساعدة في حماية البيانات أثناء انتقالها بين متصفح المستخدم والموقع.

2. حماية بيانات العملاء

نحرص على التعامل مع بيانات العملاء بطريقة مسؤولة واتخاذ إجراءات مناسبة للحد من الوصول غير المصرح به إلى المعلومات.

3. التواصل عبر WhatsApp

يتم التواصل مع العملاء عبر WhatsApp عند اختيار العميل استخدام هذه الخدمة للاستفسار عن المنتجات أو الأسعار أو الطلبات.

4. حماية المعلومات أثناء الطلب

نطلب فقط المعلومات الضرورية لمعالجة الاستفسارات والطلبات والشحن، مثل الاسم ورقم الهاتف وعنوان التوصيل.

5. خدمات وتقنيات الموقع

قد يعتمد الموقع على خدمات تقنية موثوقة لتشغيل الموقع وتحسين الأداء وقياس الزيارات والحملات الإعلانية وتحسين تجربة المستخدم.

6. مسؤولية المستخدم

ننصح المستخدم بعدم مشاركة كلمات المرور أو المعلومات السرية أو البيانات الحساسة مع أي جهة غير موثوقة.

تصفح آمن

عند ظهور رمز القفل في شريط عنوان المتصفح، فهذا يعني أن الاتصال بالموقع يتم عبر HTTPS وفقاً لإعدادات الأمان الخاصة بالموقع والمتصفح.
