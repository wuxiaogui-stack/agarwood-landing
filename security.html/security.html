网站安全

最后更新日期：2026年8月20日

1. 网站安全说明

我们重视网站访问安全以及客户信息的保护。 我们会采取合理的技术和管理措施， 尽可能降低未经授权访问、 信息泄露、数据丢失及其他安全风险。

✓

安全优先

我们持续关注网站运行及信息安全。

2. 网站连接安全

我们建议客户通过官方网站访问相关页面， 并使用安全、可靠的网络环境进行访问。

如果网站启用了 HTTPS 加密连接， 浏览器通常会在地址栏显示安全连接标识。

请注意：浏览器地址栏中的锁形图标 代表当前连接使用 HTTPS 加密， 并不代表网站获得了某项商业认证、 产品质量认证或政府机构认证。

3. 我们采取的安全措施

根据网站实际运行环境， 我们会采取合理的安全措施保护网站及相关信息。

SECURITY 01

访问控制

对网站后台及相关管理账户采取必要的访问控制措施。

SECURITY 02

数据保护

对客户提交的信息采取合理措施， 降低未经授权使用或访问的风险。

SECURITY 03

网站维护

我们会根据实际运营情况进行网站维护、 更新及必要的安全检查。

SECURITY 04

风险监控

对可能影响网站正常运行的异常情况 进行必要的处理。

4. 客户信息安全

当您通过网站或 WhatsApp 与我们联系时， 您可能主动提供姓名、电话号码、 收货地址或其他订单相关信息。

我们会根据业务需要使用相关信息， 例如：

  • 回复客户咨询
  • 确认产品信息
  • 处理订单
  • 安排配送
  • 提供售后服务

有关个人信息处理的具体内容， 请参考我们的《隐私政策》。

5. WhatsApp 联系安全

如果您通过 WhatsApp 与我们联系， WhatsApp 相关通信可能受到 WhatsApp 自身隐私政策及安全机制的影响。

我们建议您不要通过公开渠道发送 不必要的敏感个人信息。

如需进行订单咨询， 建议仅提供完成订单或配送所必要的信息。

6. 支付安全

如果订单涉及在线支付， 实际支付过程可能由第三方支付服务商处理。

我们不会要求客户通过非官方渠道 提供银行卡密码、验证码或其他 不必要的账户安全信息。

  • 不要向任何人透露银行卡密码
  • 不要透露短信验证码
  • 不要点击来源不明的付款链接
  • 如发现可疑付款信息，请及时联系我们确认

7. 第三方网站及服务

我们的网站可能包含指向第三方服务的链接， 例如 WhatsApp 或其他外部平台。

当您访问第三方网站或使用第三方服务时， 相关信息将受到该第三方自身的 隐私政策及服务条款约束。

我们无法控制第三方网站的安全措施， 因此建议您在使用第三方服务前 阅读其相关政策。

8. 安全事件

如果我们发现可能影响客户信息或网站正常运行的 安全事件，我们会根据实际情况采取合理的处理措施。

在适用法律要求的情况下， 我们可能按照相关法律规定进行必要的通知或处理。

9. 客户自身安全责任

客户也应采取合理措施保护自己的账户、 设备和个人信息。

  • 使用安全的网络环境
  • 不与他人共享账户信息
  • 不向陌生人提供验证码
  • 不点击可疑链接
  • 及时更新设备及浏览器

10. 关于安全认证及证书

本页面中的安全说明仅用于介绍我们的网站安全措施。

除非网站实际取得相关机构、 认证机构或服务提供商颁发的证书， 我们不会声称网站拥有 ISO、PCI DSS、SSL 认证、 政府认证或其他不存在的资质。

网站使用 HTTPS 与“获得某项认证”属于不同概念。 如未来获得正式安全认证或相关资质， 我们会根据真实证书信息进行展示。

11. 安全政策更新

我们可能根据网站功能、 技术环境以及适用法律法规的变化 更新本安全政策。

更新后的内容将在本页面发布， 并以页面显示的最后更新日期为准。

12. 联系我们

如果您发现网站存在可疑活动、 安全问题或其他异常情况， 欢迎及时联系我们。
